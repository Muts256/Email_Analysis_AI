#### Using AI to Analyse Phishing Emails. Does It Actually Help?

#### The Problem

Phishing remains the number one way attackers get into organisations — and 
the volume of it alone is enough to overwhelm any SOC team. Triage is 
repetitive, draining, and surprisingly easy to get wrong when you're on 
your tenth suspicious email of the day. Can AI help fix that? This project 
puts that question to the test — documenting a practical workflow and giving 
an honest verdict on whether it actually makes analysts faster, sharper, and 
less burnt out.

#### What This Project Covers

This is not a tool or a script. It is a documented methodology, a practical 
workflow for using AI as an analytical aid during phishing triage. 

It covers:
- How to structure your analysis using AI
- The prompts that work and the ones that don't
- Real case studies walked through step by step
- An honest verdict on where AI adds value and where it falls short

#### How This Repo Is Organised

| Folder | What's Inside |
|---|---|
| `methodology` | The repeatable analysis process used across all case studies |
| `case-studies` | Individual phishing emails broken down step by step |
| `prompts` | The exact prompts used and the reasoning behind them |
| `findings` | The verdict: What worked, what didn't, and what surprised me |
| `resources` | References, frameworks, and further reading |
